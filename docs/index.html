BoxBot Firmware Installer

Tinkering School Mars Mission

🚀 Flash Firmware

Install or update the BoxBot firmware directly in your browser — no drivers or software installation required.

v0.7
⚠️ Unsupported browser. Please use Google Chrome or another Chromium-based browser (Edge, Opera, Brave) on a desktop computer. Firefox and Safari do not support the Web Serial API.

After flashing, connect to the boxbot**** Wi-Fi network that appears, then open http://192.168.4.1 in your browser to control the robot.

📋 Before You Start

  1. Use the black USB cable that came with the robot (the white one is charging-only).
  2. Use Google Chrome, Microsoft Edge, or another Chromium-based browser on a desktop computer.
  3. Click Connect, select the BoxBot's serial port, then click Install BoxBot.
  4. On Linux, you may need to add yourself to the dialout group first: 
    sudo usermod -a -G dialout $USER
    Then log out and back in.

✅ After Flashing

  1. Power the robot on with the battery pack connected.
  2. On your device, join the boxbot**** Wi-Fi access point (e.g. boxbot52C8).
  3. Open http://192.168.4.1 in your browser — make sure to type http://, not https://.
  4. Start exploring the robot controls!
